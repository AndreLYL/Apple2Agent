# Changelog

## 0.5.0-alpha.1 — public-source candidate

- Calendar, mail, reminders, contacts, notes, selected files and experimental Messages modules.
- Scoped resource grants, revisions, stable request IDs and frozen native send approval.
- Optional private mobile connector; no shared backend or credentials.
- Portable configuration examples, synthetic test data and public installation/privacy documentation.
- macOS build/test workflow and publication privacy checks.

This is a source alpha. See [compatibility](docs/compatibility.md) for the difference between implemented, automated-tested and live-verified capabilities. A candidate entry does not mean a GitHub release has already been published.
